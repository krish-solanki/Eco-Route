# eco_route

A new Flutter project.

## Getting Started# 🌱 Eco Route

Eco Route is a Flutter application that helps users choose cleaner and healthier travel routes by providing real-time air quality and weather information. The app is designed to encourage eco-friendly travel decisions and improve daily commuting.

---

## ✨ Features

- 🔐 Firebase Authentication
- ☁️ Cloud Firestore integration
- 📍 Route planning
- 🌍 Real-time Air Quality information
- 🌦️ Weather updates
- 🗺️ Interactive Maps
- ❤️ Save favorite locations
- 📱 Responsive UI
- 🚀 Riverpod state management
- 🔄 REST API integration

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Git
- Firebase CLI (Optional)

---

### Installation

1. Clone the repository

```bash
git clone https://github.com/krish-solanki/eco_route.git
```

2. Navigate to the project folder

```bash
cd eco_route
```

3. Install dependencies

```bash
flutter pub get
```

4. Run the application

```bash
flutter run
```
